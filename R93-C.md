# R93 · C — Website › SEO

## Built
- `admin/site.js` (C fence only): `loadSiteSeo({refresh})` paints `#page-site-seo` from the latest `seo_snapshots` day in two reads (`select day order desc limit 1`, then `select * eq day limit 1000`).
  - Header strip `#seo-head`: "Last audit <fmtAgo> · <n.n>s" + `#seo-run` **Run audit now** → `db.functions.invoke("seo-snapshot", { body: { force: true } })`. While running: disabled, `aria-busy`, spinner (`.seo-spin`). Afterwards: toast ("Audit finished." / "… · N steps failed" / "Audit failed: <msg>"), then a re-read.
  - Four kit tiles `#seo-tiles` (`.kpi-row` / `.kpi` / `.num` / `.lbl`, `warn`/`bad` like Data health): `#seo-tile-pages`, `#seo-tile-issues` ("E · W"), `#seo-tile-psi` (PSI avg, "—" until connected), `#seo-tile-gsc` (clicks 28d, or "Connect", which scrolls to the Connect panel).
  - One table `#seo-table` (`imp-table mob-cards`, header row in tbody so the phone card layout works): Page · Title · Description · H1 · Words · PSI · Clicks · Position · Issues. Length chips green/amber/red (title 30–60, description 70–160, missing = red). H1: 1 green, 0 red, more than 1 amber. PSI ≥90 green, ≥50 amber, below that red. A non-200 status shows as a red chip next to the path. Issue chips (`.seo-chip`) are grouped by code ("Broken link ×2"): red for error, amber for warn, every message in `title`. Clicking a row toggles a `<details>` that holds the issue list and the broken links. A clean page shows a green ✓ and has no details. Rows are sorted by errors, then warnings, then path.
  - Top queries: `gsc_query` rows sorted by clicks (then impressions), at most 20, drawn as R88 kit rows (`rowItemHtml`) in `#seo-queries`. When `gsc_connected` is false this becomes the three-line Connect panel `#seo-connect` instead.
  - Empty state `#seo-empty`: `emptyState({headline:"No audit yet."})` + the Run button.
  - Every top-level name starts with `seo` / `SEO_`, except the registered `loadSiteSeo`. There are no inline styles and all text goes through `esc()`.
- `admin/admin.css`: the `/* ===== R93 · C CSS ===== */` fence sits directly above the R90 utilities block, with no @media.
- `tests/r93_seo.js` has 40 checks. `REPO`/`PORT` can be overridden with `NX_REPO`/`NX_PORT`.

## Guesses
- GSC `page` may be a full URL. `seoPath()` normalises both sides: it strips the origin and the trailing slash and adds a leading `/`.
- Fallbacks when there is no `summary` row: pages, errors and warnings are counted from the audit rows, and the PSI tile shows "—". PSI counts as connected only when `psi_connected !== false` and `psi_avg` is non-null.
- "When" is `summary.ran_at`, falling back to the row's `created_at` and then the day.
- A function error is treated as failed whether it arrives as `{error}` (supabase-js on a non-2xx) or as `{data:{error}}` (the current mock invoke).
- The issue labels (`SEO_ISSUE_LABEL`) are my own short wording.
