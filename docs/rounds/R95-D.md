## js-class one-liner: kept inline, allowed by hash

`<script>document.documentElement.classList.add('js')</script>` must run before first paint (reveal styling without
a flash of unstyled content). An external file would add a render-blocking request to every page; a hash costs nothing. It is byte-identical on
all 15 pages that carry it (A23), and `build.js` copies it unchanged into rendered guides.
`'sha256-Du+OJKJSbdUgz5nrHeWWINvez6XKDDU/tyj/5c2uvwo='`: pinned in the suite (`JS_CLASS_HASH`, A8/A8b), so changing a byte fails the suite.
