## Checked and clean (held under attack)

- **CSP hash**: `sha256-Du+OJKJSbdUgz5nrHeWWINvez6XKDDU/tyj/5c2uvwo=` = `document.documentElement.classList.add('js')`. It is the only non-JSON-LD inline script on all 14 root pages and on `guides.template.html`. Public script-src has no `unsafe-inline` or `unsafe-eval`. `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, and XFO DENY apply site-wide (`/(.*)`, including /admin). connect-src is `'self'` plus the one Supabase project, which matches every `fetch` in `js/*.js` and `unsubscribe.js`.
- **`style-src 'unsafe-inline'` / `img-src https:`**: no HTML-injection sink on any public page, so there is nothing to abuse them with. Every `innerHTML` in `js/*.js` and `enhance.js` is a constant or `esc()`'d (`js/docs.js:44-63, 263`, `js/factfind.js:73`, `js/feedback.js:72` writes a constant and then uses textContent). No `document.write`, `postMessage` listener, `eval` or `location.hash` sink exists. `?type=` on contact (`js/contact.js:37`) only selects an existing `<option>` by exact value.
- **`window.__NEX_FN_BASE` override** (`js/docs.js:8`, `js/feedback.js:6`, `unsubscribe.js:9`): could only be set by DOM clobbering, which needs markup injection. None exists, and connect-src would block a foreign base anyway.
- **data-act kit as a gadget** (`enhance.js:36-55`): reachable only through injected markup. The guides allowList strips all `data-*` attributes (`build.js:240-253`). The native-function hardening was already deferred in R95-no-inline.md "R96 candidates", so it is not re-reported.
- **Header source patterns**: `/((?!admin).*)` vs `/admin/:path*`. Under path-to-regexp, `/admin/:path*` also matches bare `/admin`, the URL the app is actually served at (`trailingSlash:false`). `/admin.html` and `/admin/index.html` are cleanUrls-redirected to `/admin`. `/ADMIN/` and `/Admin/index.html` hit a case-sensitive 404. `/administrator` and `/admin-x` get no CSP but are Vercel's static 404, with no injection. Query strings don't affect matching. Admin HTML is `no-store`. Admin JS/CSS is `public, max-age=0, must-revalidate` (`vercel.json:227`), which shared caches may store, but the files hold code and the anon key only.
- **Redirects** (33, `vercel.json:7-205`): every destination is a literal. No `:slug` is carried into a destination, there are no `has`/host conditions and no loops (each `:slug+` collapses to a parent that exists as a file). So no open redirect.
- **Token pages** (`factfind`, `docs`, `feedback`, `unsubscribe`): each has `<meta name="robots" content="noindex, nofollow">` and loads **no** third-party resource (no fonts, no CDN), so `?token=` / `?t=` never reaches a third party. Off-site navigation (the feedback promoter redirect) sends origin only under `strict-origin-when-cross-origin`. Tokens go in the POST body for uploads (`js/docs.js:197`). unsubscribe `?format=json` returns only `{ok,valid}`, with CORS pinned to the two site origins (`edge/unsubscribe-v4.ts:35,126`). Nothing is reflected.
- **Fact-find data model**: DOB, nationality, residency, address, income, credit issues and protection, for two applicants (`factfind.html` names). No NI number, bank details or passport. The token-gated prefill is filled with `.value`, never HTML (`js/factfind.js:19-35`).
- **dist/ contents**: the full build ships 53 files. Root `*.html`, `js/*.js`, `enhance.js`, `unsubscribe.js`, style/logo/favicons, `assets/{hero-loop.mp4,hero-poster.jpg}`, `admin/{index,introducer}.html` + 11 admin scripts/css/manifest/sw/sw-kill + icons, robots, sitemap, llms.txt. Absent: `.map` files, `.md`, `deploy.bat`, `.env*`, `package*.json`, `mock.html`, `mock-supabase.js`, `tests/`, `db/`, `edge/`, `supabase/`, `docs/`, `.github/`, `guides.template.html`. The only JWT in dist decodes to `role:"anon"` (app.js, introducer.js). Admin HTML comments mention no secrets.
- **Build-time content** (R93): `site_pages` title/meta/H1/FAQ/og:image are escaped, og:image needs `https://`, JSON-LD goes through `jsonForScript`, slugs match `SLUG_RE`. The fixture with `</title><script>`, `<img onerror>` and an `og:image` quote breakout rendered inert. Marked raw HTML is escaped (`build.js:261`). The build fails closed. `site_pages` going live without owner approval was accepted in the R93 contract (R93-VERIFY #9), so it is not re-reported.
- **robots.txt / sitemap.xml / llms.txt**: list only public pages. `/admin` is disallowed and also noindex via `X-Robots-Tag`.
- **Service worker** (`admin/sw.js`): network-first and same-origin `/admin/*` GET only, so it can never serve stale code while online. The kill switch is `admin/sw-kill.js`. Observation: it is registered with scope `/admin/` (`admin/boot.js:23`), but the back office is served at `/admin` with no slash (`trailingSlash:false`). So it controls only `/admin/introducer` and never the main admin page. A stale-SW-after-security-fix scenario is therefore impossible for the main app. The flip side is that the offline page and caching are effectively inert. This is a correctness note, not a security one.

## UNVERIFIED (needs a live `curl -sSI` from an unproxied machine)

1. Encoded admin paths: `/admin%2Findex.html`, `/%61dmin`. If Vercel normalises the path for the filesystem but matches header `source` against the raw path, the admin page would be served with the *public* CSP and without `no-store`/`X-Robots-Tag`. The public CSP would break the app (jsDelivr blocked) rather than weaken it, so the expected impact is low. To settle it: `curl -sI 'https://www.nexmoney.co.uk/%61dmin'` and compare the headers with `/admin`.
2. Apex→www and http→https: these are Vercel domain settings, not in the repo. `preload` is declared, but hstspreload.org reports `nexmoney.co.uk` status `unknown` (not on the list). To settle it: `curl -sI http://nexmoney.co.uk/`, which should 308 to https and carry HSTS with `includeSubDomains` on the apex if preload is intended.
